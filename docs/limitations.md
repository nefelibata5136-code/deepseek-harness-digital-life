# Known limits

- Framework is experimental, not an unattended appliance or consciousness claim.
- Deployment acceptance, new clean-export tests and external acceptance differ.
- DSH Session/compaction/provider internals are version-sensitive.
- No identity, live state or login configuration is supplied.
- Windows DPAPI/native desktop/terminal/browser ownership have platform limits.
- Full same-user OS access undermines absolute credential/Vault isolation.
- Computer Use has partial application coverage; browser restore is unaccepted.
- Dots/Slack genuine complete round trip is still unaccepted.
- Periodic Resident is off; missed windows are not replayed as actions.
- Budget prices are dated and expire; reservations/estimates/debits differ.
- Standby service/private known-good copies/desktop bootstrap are excluded.
- Scanners and ignore rules cannot replace staged-tree/history/text review.
